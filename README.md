# Examcoo Study Helper

一个运行在 Edge + Tampermonkey 中的考试酷本地学习测试助手。

本项目因家人学习需要制作，仅供学习、交流和本地测试使用。脚本不修改考试酷网站源代码或服务器程序，不绕过登录、验证码及安全机制，也不会自动点击“检查”“临时保存”或“交卷”。所有提交操作均由用户本人检查后手动完成。

## 功能

- 区分考试酷答题页 `/editor/do/exam/...`、结果页 `/editor/do/recur/...` 与班级考试页 `/class/paper/...`。
- 只把考试酷公布的官方参考答案保存到本地题库；不保存用户手动作答，也不保存 AI 的作答。
- 答案一律按选项内容定位，不按字母位置，因此页面上选项乱序也不会填错位置。
- 自动回填本地题库中已经收录的题目。
- 班级考试页可一次性抓取本班全部考试的参考答案，抓取前与入库前各确认一次。
- 可调用 DeepSeek 临时分析当前页面尚未作答的题目：开启思考模式、参考本地题库中的相似题、低置信度的题目自动多轮复核。
- 支持 JSON 题库导入、导出。
- API Key 不会写入脚本或导出的题库文件。

## 安装

1. 在 Edge 中安装 Tampermonkey。
2. 打开 Tampermonkey，选择“添加新脚本”。
3. 删除示例内容，将 `examcoo-study-helper.user.js` 的完整代码粘贴进去。
4. 保存脚本并刷新考试酷页面。

## 页面功能

悬浮面板支持拖动位置、收起内容和关闭隐藏。关闭后页面会保留一个小型“助手”按钮，点击即可恢复；拖动位置会保存在浏览器本地。

### 答题页

- **重新识别**：重新读取当前页面题目和输入框。
- **回填已保存**：使用本地官方题库自动勾选已收录题目。
- **AI分析未作答题**：仅临时分析和勾选当前未作答题目，不写入题库。勾选后按置信度在题目左侧显示绿/黄/红竖条，鼠标悬停可看判定依据。
- **AI复核已勾选**：让 AI 独立复核页面上已经勾选的答案，有分歧的题目标红并写明“当前选择 / AI 建议”。
- **导入题库 / 导出题库**：备份、迁移或合并官方参考答案题库。

### 结果页

- 自动读取网站已经公布的参考答案并保存。
- **保存本页正确答案**：手动再次执行结果页答案收录。
- 保存的是 `.optionContent` 对应的完整选项内容，而非当前显示字母。

### 班级考试页

- **批量抓题库**：读取本班班级考试列表的全部页，逐条取成绩列表里“我自己”那一行的答卷，解析其中的参考答案。
- 抓取前会先列出覆盖页数、记录数、预计请求次数与耗时，点“开始抓取”才会真正开始；抓取过程中按钮变为“中止抓取”。
- 抓完后列出识别到多少题、可入库多少题、哪些场次可能没抓全，点“合并入库”才会写入本地题库，点“取消”则全部丢弃。
- 抓取期间会在隐藏的 iframe 中加载答卷页，因此那段时间请不要关闭当前页面。

## 题库规则

本地永久题库只保留来源为 `examcoo-reference` 的成绩页正确答案。脚本启动和导入题库时都会过滤 AI 作答及用户手动作答记录。

回填时优先按选项文字匹配：只要页面上某个选项的内容与答案文字一致就选中它，与它在页面上排第几个无关。只有当页面选项文字对不上（例如被加了序号前缀）时，才退回按输入框的 `1、2、4、8、16` 位值定位；而且退回前会先逐项核对页面选项顺序确实与题目数据一致，对不上就判为未匹配、交给人工处理，不会按位置猜。

## AI 分析

在答题页展开“AI 设置”，填写自己的 API Key 并保存。可配置模型名称、是否开启思考模式、每批题数、复核轮数和高置信度阈值。

AI 只在你手动点击时调用，结果只临时勾选在当前页面上，不会写入本地题库。调用可能产生费用，返回的答案也可能出错，请在手动提交前自行检查。
